# 南京市内智能行程表 · 引导对话与无边框版

2026-10-29，Windows x64 桌面版。保留多表、周期、冲突、地图、提醒和手动填表，在此基础上接入新版导航、日期时间选择与连续对话。周课表入口保持移除。

## 运行和数据

解压完整运行包后启动 `NanjingPlanner.exe`，无需另装 .NET。请保留同目录的组件文件。程序旁 `Data` 保存 SQLite 行程、看板偏好、加密服务设置及本地对话；关闭软件后备份整个目录。旧版运行包和数据不会被新包覆盖。

首次空库自动加入数量错落的示例活动，包含长备注和跨日安排；已有数据库不重复注入。示例可以编辑、收藏、完成或删除。

## 导航与设置

- 左上为行程看板、我的行程表、地图、智能助手，左下为本地头像昵称和齿轮设置。导航默认仅显示图标，悬停显示文字提示；Ctrl+B显示/隐藏左侧行程表面板。
- 我的行程表从左侧展开；助手从右侧展开。看板保留在中间，两侧可同时打开。地图继续使用完整独立窗口。
- 设置是独立窗口，支持搜索和外观、个人资料、智能服务、地图、数据分类。字号12—22、模式和置顶仅在设置中调整。
- 主窗口及设置/编辑/确认窗口使用同色无系统边框顶栏，保留拖动、双击标题区域最大化、边缘缩放和右上窗口控制。
- 本地资料只保存头像字样与昵称，没有联网注册或登录。

## 行程表、看板和操作

- 新建行程表提供12种主色，必须选择后保存；旧表自定义颜色会保留。卡片色条和表名颜色对应所属表。
- “显示”控制是否可见，“生效”控制排程与冲突约束；隐藏但生效的表仍参与检查。
- 月历沿用暖红日期、灰底与暖白圆角卡片。点击日期格空白添加，点击卡片编辑，保留全部原有字段。
- 列表左侧独立展示开始时间、当日耗时和结束时间，右侧保留标题、地点、备注、所属表、周期和核验提示。
- 左滑一次切换完成，再次左滑恢复；完成会淡出。右滑一次切换收藏，再次右滑取消；仅已收藏显示星标。右键提供相同操作，Shift+Enter切换完成，Ctrl+S切换收藏。
- 自动/完整/简洁模式可切换；简洁展示今天及随后六天。自动按尺寸、比例和字号采用迟滞，避免临界尺寸来回跳动。

## 日期、时间和跨日

点击日期弹出暖色月历，点击时间或旁边时钟弹出小时/分钟双滚轮，支持鼠标滚动、拖动、触摸和键盘上下键；也可在弹窗输入HH:mm，精确到分钟。

分钟59→00进一小时，23时→00时进一天，反向相应借位；选择器始终显示实际日期。确定才应用，取消无副作用。开始与结束各有完整日期：修改开始默认保持时长并联动结束，修改结束重新计算耗时；手工结束早于开始会明确提示，不猜测次日。保留30/60/90/120分钟快捷时长。

跨日底层是一条活动，在每一天展示当日片段。例如23:30—次日01:00显示23:30—24:00与00:00—01:00，并标明接续、本日30/60分钟与全程90分钟。所有片段共享编辑、完成与收藏状态。活动存储时长沿用1—10080分钟上限。

## 连续引导式对话

助手保留同一分支上下文，根据已知信息追问必要缺项；不要求固定四轮或固定填表格式。需求足够时先显示汇总，再生成可编辑草稿。模型使用的固定提示词与协议见 `Planner.Data/GuidedAgentClient.cs`。

每条用户消息可编辑重发：从该处创建新分支，旧分支及后续消息保留。分支切换/编辑会取消当前回答，迟到回复不会混入新分支；已打开的旧草稿不能在新分支下写入。已经保存的行程不随对话修改而自动改变。

草稿可保存到现有表，也可新建表并从12色中选色。软件自动查询地点，唯一结果自动填入，多候选请确认；之后沿用交通比较、时间冲突、版本检查和最终核对，再一次写入整批。新表也仅在最终确认时创建。明确指定的夜间/跨日时间按真实区间规划；未指定开始时默认在08:00—22:00寻找最早可行空档，最多15项。

每个生成批次都有本地凭据，可在相应对话分支撤回。撤回只删除该批次拥有的数据，不整库回滚；其他手动新增行程保留。生成活动、提醒被手动修改，或已关联新路线/周期时，会拒绝静默撤回并说明。中断后的写入/撤回意图会在重启时结合数据库恢复状态。

未配置模型时使用明确标识的本地规则引导，支持补齐带日期、地点、耗时的单项活动及明确出行/提醒偏好；复杂多项、地点推荐与细致偏好理解需要连接模型。周期活动仍可通过原手动编辑器维护，助手生成批次为待核对的单次活动。

## 智能服务、地图和提醒

在设置连接本地规则、自定义兼容接口、百炼或已有服务配置。兼容接口需要支持 Chat Completions；密钥由当前 Windows 用户加密。保存设置不会发起请求。模型只收到当前分支对话和当天日期，不默认上传已有数据库或私有备注；不直接修改数据库，不编造坐标、真实费用、拥堵或营业状态。

高德Web服务Key用于搜索和路线，JS Key与securityJsCode用于内嵌地图。未配置时，仅使用明确标识的南京预置地点和直线粗估，不能视为真实路程；配置后的联网查询失败不会伪造成功。公交包含地铁及接驳步行；打车可按驾车路程评估并在备注保留打车要求，费用未知时保持未知。

提醒仅软件运行时有效，退出不会后台发送。完成标记只改变看板显示，不自动取消排程和提醒。时间统一按北京时间。

## 构建和检查

使用 .NET SDK 10.0.201。`build.ps1` 执行核心检查并发布完整 win-x64 运行包，可指定 `-OutputDirectory` 和 `-PackageDirectory`。原生界面检查由 `Planner.BoardChecks` 执行，必须传入新的隔离目录，不能指向个人Data。

本版已用可控HTTP响应验证真实模型请求协议与多轮流程，没有使用真实付费模型或地图密钥进行联网联调；触屏硬件、多个显示器/DPI组合及实际出行仍需在对应环境确认。详见 `VERIFICATION.md`。
