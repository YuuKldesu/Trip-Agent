# 南京市内智能行程表 · 最新功能整合版

整合合作方feature/ui v1.12.9（978c678）与本地WPF多表、周期、冲突、地图和提醒。整体保留暖色风格。周课表已移除。

## 运行与示例

解压整个运行包后，双击NanjingPlanner.exe。包含.NET运行组件，无需安装SDK，仅支持64位Windows。程序目录需可写。

首次创建新数据库时，自动加入明确标注的示例活动。相邻七天数量为1、3、0、5、2、1、4，另有跨日和长备注，方便检查不同密度。已有数据库不添加、不覆盖；重新打开不重复注入。可直接编辑或删除示例。数据在程序旁Data目录，请关闭程序后备份整个Data，不要把自己的Data或服务密钥随软件分享。

## 月历和列表

- 默认月历，周一至周日。点击日期格的空白位置打开自定义添加；日期数字选择当天，活动卡片打开编辑，完成按钮只标记完成。逐日加号和周课表入口已删除。
- 行高随内容增长；首次打开、窗口尺寸变化和视图切换均按实际可视高度填满。密集日期竖向滚动查看，窄窗口横向滚动时星期表头同步。
- 月历/列表保留各自滚动位置并缓存；数据和显示状态变动会更新。支持独立显示已完成、未完成，两项都关闭时为空。
- 左侧“显示”控制表内卡片可见，“生效”控制排程与冲突约束。隐藏生效表仍参与检查。
- 列表按日期分组，短间隔包含交通时间。因支持无限每周周期，初始展示当前月，可逐月追加，最多连续6个月；超过后切换月份继续查看，不无限展开周期。

## 自定义添加与编辑

编辑器采用紧凑双列布局，可调整窗口大小，主窗口仍可操作。日期带日历，时间支持手写HH:mm或下拉选择；起止时间自动计算耗时，30/60/90/120分钟快捷项同步结束时间。日历和时间下拉可点击外部关闭，Escape关闭编辑器。

更多设置保留所属表、每周重复、多星期、重复结束日、单次/未来规则调整、灵活时间窗、跨日和提醒。周期默认仅改当前一次，修改整套规则保留历史与单日例外。

时间重叠按仓库逻辑拒绝保存。启用“保存前核验相邻交通”时，搜索并确认地点，校验前后通行时间，查询失败不会保存；默认对已有坐标的活动启用。日常未确认地点或跨日活动仍可手动保存为待核验，再到地图中完善。保存前展示影响，异步检查期间原行程变化会要求重新打开。

## 智能行程助手

采用仓库流程：描述需求 → 识别活动 → 完善行程 → 查询/选择交通 → 预览 → 批量确认保存。

在服务设置选择本地规则、自定义兼容接口、百炼或DeepSeek；旧设置自动沿用兼容接口。本地规则不联网，只支持带日期、地点、耗时的一项活动，如“明天下午2点在南京博物院参观，2小时”；复杂多项使用配置模型服务。百炼选择北京/新加坡，可填写匹配的业务空间API Host。配置保存不会发起模型请求。

识别后最多15项，逐项核对标题、日期、起止/耗时、地点、最晚到达/结束、前往方式和备注。开始时间留空表示自动安排。地点搜索结果需要确认；修改关键词后原选择失效。可比较与上一项的公交、步行、骑行和驾车方案。公交包含地铁和接驳步行。

自动安排按输入顺序，在08:00—22:00选择最早可行空档，已有生效活动固定，检查前后交通。明确时间有冲突会拒绝，不能强行保存。返回修改或取消不写入；确认后校验原行程版本，再统一保存。返程到达点在现有正时长存储模型中占1分钟，并标注“返程到达标记”，避免与下一项重叠。

模型只收到用户输入和当天日期，不上传现有表、备注或数据库；不是通用任意数据库修改代理。模型提取的缺项允许在完善窗口补齐。接口需要兼容Chat Completions，密钥使用当前Windows用户保护。未进行真实付费模型调用验证。

## 地图、费用与提醒

高德Web服务Key用于搜索/路线，JS Key和securityJsCode用于内嵌地图。未配置高德时，完善窗口可使用预置南京地点与明确标注的直线粗估，不能视为真实路程；配置后使用高德查询，失败不伪造结果。原地图与路线窗口继续支持多方式方案、地图几何、已知费用与未知项、线路确认及重排。

智能助手的路线摘要保存于备注；完整地图方案仍由“地图与路线”功能确认管理，两者不冒充实时监测。高德账号权限、配额、模型兼容、在线地图和真实路线需要用户配置后联调。本次没有验证真实出行。

提醒仅程序运行时有效，退出后不提醒；完成标记只改变看板显示，不取消原排程/提醒。所有时间按北京时间。

## 构建

使用.NET SDK10.0.201，打开NanjingPlanner.sln，或运行build.ps1。脚本执行行为检查并发布win-x64完整运行包，可用-OutputDirectory指定独立目录，-PackageDirectory指定依赖缓存。

Planner.Tests为行为测试；Planner.BoardChecks通过真实WPF控件事件检查界面与保存流程，需传入新隔离目录，不要指向自己的Data。源码包不包含依赖缓存、编译文件、用户Data或密钥。
