# 南京行程 Agent

桌面端南京行程规划原型，界面借鉴「场记」的日程与票夹气质。Python 标准库实现，无需安装第三方包。

## 启动

需要 Python 3.10 或更高版本及 Tkinter（Windows/macOS 官方安装包一般自带；Linux 可能需要安装 python3-tk）。解压后在项目目录运行：

```bash
python app.py
```

Windows 也可双击 `启动.bat`。数据库在用户目录的 `.nanjing_trip_agent/trips.sqlite3`，配置保存在同目录的 `config.json`。备份时复制整个目录。

## 配置和使用

1. 在设置中可选择主题色；保存后立即生效并记住选择。在设置中选择“本地规则”“DeepSeek”或“阿里云百炼”。选择云端服务时，在对应的 Key 栏填写密钥；百炼还需选择 Key 所属地域（北京或新加坡），使用 qwen-plus。可选填写百炼业务空间的 API Host（在百炼控制台业务空间管理页面获取）；留空使用该地域共享域名。高德开放平台需填写「Web 服务 API」Key。云端接口需要相应权限及额度，请留意实际费用。
2. 输入如「明天在南京博物院参观，约2小时」或「2026-11-02下午2点在夫子庙吃饭，90分钟」。点击规划后在“完善行程”面板中统一核对日期、地点、开始/结束时间与交通方式。地点可重新搜索并从候选中选择；填写开始与结束时间可自动计算耗时，也可点选常用耗时。相邻活动支持查询公交、步行、骑行和驾车估算并选择方式。
3. 在确认窗口核对识别结果、地图地点和相邻活动的路线耗时，再确认保存。在月看板中查看整月的全部行程，使用左右箭头切换月份或点击“今天”返回本月；向下滚动查看超出屏幕的日期和卡片。日期格子会根据行程内容自动增高。月历活动卡片显示时间、标题、地点、耗时和备注，点击可编辑完整详情，也可点击卡片或“编辑”修改活动、日期、时间、地点、耗时和备注，或直接删除。编辑时按弹窗中选择的交通方式重新检查相邻行程（编辑时前后两段共用该方式），保存前展示重新查询的地点与交通时长。点击“列表”可切换为按日期分组的全部月份行程列表，顶部日期随列表滚动更新，点击圆形标记完成或撤销完成，状态保存在本地；同一天相邻活动的间隔不足 60 分钟时，在卡片之间标注空档时长（该时长包含交通时间，不代表交通后的剩余时间）。新行程的备注由大模型从对应活动中提炼，未提供额外信息时可以为空；本地规则不生成摘要。已有备注不会自动更改，可手动编辑。

选择本地规则时使用简单规则，支持今天、明天、后天、完整日期或本年月日，地点需写在「在/去/到」之后，耗时需明确写数字；本地规则不支持复杂多事件、相对星期或模糊时段，多活动请使用云端解析。未配置高德时只支持南京南站、南京站、新街口、夫子庙、南京博物院、玄武湖、中山陵、南京大学、总统府，交通时间仅根据直线距离粗估。接入高德时提供南京地点搜索候选供选择，每项地点需要从候选中选择。结果未列出目标地点时，可在面板中更换关键词重新搜索；找不到路线时会拒绝保存，不会伪造通行时间。公交路线可包括地铁及步行接驳；不会自动规划“骑行加地铁”组合，也不展示交互式地图。

## 排程规则与限制

- 接入 DeepSeek 或百炼后可一次输入最多 15 项活动与返程，按提及顺序安排；只在 08:00–22:00 安排，既有行程视为固定，从早到晚寻找第一个可行空档。
- 检查新活动与前后相邻活动间的交通时间；明确指定时间时若冲突就拒绝。第一项无出发地，不计算去程；最后一项不计算返程。
- 路线时间是查询时的估计，并非未来指定时刻的保证，建议出行前重新核实。删除行程不会重排其他活动，已保存的路线耗时不会自动刷新。
- 使用云端解析时，输入文本会发送至所选的 DeepSeek 或阿里云百炼；地点和坐标会发送至高德。密钥明文保存在本机配置文件，不要分享此文件。
- 这是可运行的原型，未打包成安装程序；提醒、全局最优重排等尚未实现；多活动按输入顺序寻找可行时段，不保证全局最优。

## 网络故障排查

高德地点或路线查询遇到临时连接中断时会自动重试。若提示 HTTPS 提前中断，请检查代理或 VPN 配置、切换网络后重试；DeepSeek 请求不会自动重试以避免重复计费。错误提示会标明失败阶段，但无法单凭该错误确定是服务器还是本地网络的问题。请勿将 API Key 发给他人。
