# 南京行程 Agent

桌面端南京行程规划原型，界面借鉴「场记」的日程与票夹气质。Python 标准库实现，无需安装第三方包。

## 启动

需要 Python 3.10 或更高版本及 Tkinter（Windows/macOS 官方安装包一般自带；Linux 可能需要安装 python3-tk）。解压后在项目目录运行：

```bash
python app.py
```

Windows 也可双击 `启动.bat`。数据库在用户目录的 `.nanjing_trip_agent/trips.sqlite3`，配置保存在同目录的 `config.json`。备份时复制整个目录。

## 配置和使用

1. 在设置中可选择主题色；保存后立即生效并记住选择。在设置中填写 DeepSeek API Key 和高德开放平台「Web 服务 API」Key；需要相应接口权限和额度。也可以留空体验。
2. 输入如「明天在南京博物院参观，约2小时」或「2026-11-02下午2点在夫子庙吃饭，90分钟」。选出行方式后点击规划。
3. 在确认窗口核对识别结果、地图地点和相邻活动的路线耗时，再确认保存。在月看板中查看整月的全部行程，使用左右箭头切换月份或点击“今天”返回本月；向下滚动查看超出屏幕的日期和卡片。日期格子会根据行程内容自动增高。活动卡片直接显示时间、标题、地点、耗时和完整原始输入作为备注，也可点击卡片或“编辑”修改活动、日期、时间、地点、耗时和备注，或直接删除。编辑时按弹窗中选择的交通方式重新检查相邻行程，保存前展示重新查询的地点与交通时长。点击“列表”可切换为按日期分组的当前月份行程列表；同一天相邻活动的间隔不足 60 分钟时，在卡片之间标注空档时长（该时长包含交通时间，不代表交通后的剩余时间）。旧版本的行程会保留；旧记录原本没有保存原始输入，因此备注为空。

未配置 DeepSeek 时使用简单规则，支持今天、明天、后天、完整日期或本年月日，地点需写在「在/去/到」之后，耗时需明确写数字；不支持复杂多事件、相对星期或模糊时段。未配置高德时只支持南京南站、南京站、新街口、夫子庙、南京博物院、玄武湖、中山陵、南京大学、总统府，交通时间仅根据直线距离粗估。接入高德时地点选择南京搜索结果第一条，请在确认窗口核对；找不到路线时会拒绝保存，不会伪造通行时间。

## 排程规则与限制

- 单次输入一项活动；只在 08:00–22:00 安排，既有行程视为固定，从早到晚寻找第一个可行空档。
- 检查新活动与前后相邻活动间的交通时间；明确指定时间时若冲突就拒绝。第一项无出发地，不计算去程；最后一项不计算返程。
- 路线时间是查询时的估计，并非未来指定时刻的保证，建议出行前重新核实。删除行程不会重排其他活动，已保存的路线耗时不会自动刷新。
- 接入 API 时，输入文本会发送至 DeepSeek；地点和坐标会发送至高德。密钥明文保存在本机配置文件，不要分享此文件。
- 这是可运行的原型，未打包成安装程序；复杂地点歧义、编辑行程、提醒、全局最优重排等尚未实现。


## 网络故障排查

高德地点或路线查询遇到临时连接中断时会自动重试。若提示 HTTPS 提前中断，请检查代理或 VPN 配置、切换网络后重试；DeepSeek 请求不会自动重试以避免重复计费。错误提示会标明失败阶段，但无法单凭该错误确定是服务器还是本地网络的问题。请勿将 API Key 发给他人。
