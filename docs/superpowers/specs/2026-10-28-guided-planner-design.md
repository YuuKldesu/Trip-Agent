# 引导式行程与新版桌面 UI（已确认设计）

用户在对话中逐项确认，并于 2026-10-28 授权开始实现。本文件记录已经确认的范围，不再另设设计审批。

## 界面
- 继续使用 WPF、现有 SQLite 和暖色圆角风格，保留所有行程字段、手动操作、周期、提醒、地图和冲突检查。
- 左侧图标导航，Ctrl+B 展开或收起文字。底部为本地头像昵称、齿轮设置。行程看板为主页。
- 我的行程表在导航旁展开左面板；智能助手在主窗口右面板展开，不切走看板。地图沿用现有完整功能。
- 设置为独立、相对主窗口居中的窗口：搜索、左分类、右内容。字体、布局、置顶、服务配置仅位于设置内。
- 保留现有月历灰底、暖红日期头、白色圆角卡片和空白日期添加。列表左侧独立显示开始、当日耗时、结束时间。
- 行程按所属表主色显示色条及表名，新增表提供 12 色并要求用户选择；已有自定义颜色不因编辑被覆盖。
- 左滑切换完成并淡出，右滑切换收藏；仅已收藏显示右上角星标。两状态独立，跨日片段同步；保留右键及键盘入口。
- 简洁模式保留今天及随后六天，不恢复周课表。

## 日期、时间与跨日
- 点击日期或时间，分别弹出暖色圆角选择器；时间为小时/分钟双滚轮，保留 HH:mm 输入及分钟精度。
- 分钟循环进退向小时进位/借位；小时循环进退向日期进位/借位。选择器始终显示日期；确定才应用，取消无副作用。
- 完整开始、结束日期时间；修改开始默认保持时长联动结束；修改结束更新时长。手动输入结束早于开始时明确拒绝，不猜测次日。
- 保留 30/60/90/120 分钟快捷时长、周期范围、灵活范围及提醒。沿用底层 1—10080 分钟约束，不扩大数据库允许范围。
- 一条跨日行程按天投影：23:30—24:00、次日00:00—01:00；标注跨日/接续、本日30/60分钟及全程90分钟。底层不复制活动，统计用真实区间、统一状态，午夜不多生成零时长片段。

## 真正的引导对话逻辑
- 固定系统提示词约束自然中文引导：理解目标、日期和可用时间、事项地点耗时、出行及偏好，只追问缺失项，不强制四轮问答。
- 每个分支保留用户与助手上下文。编辑任意用户消息从该处创建新分支并重新推演，保留旧分支及后续消息；不自动改动已经写入的行程。
- 支持已配置的兼容模型/百炼等服务；未配置模型时有明确标识的本地规则引导，能力不足时提示补充或手动完善，不能冒充联网智能。
- 提示词和结构化响应必须在仓库内实现。模型不直接写数据库，不生成坐标、价格、拥堵、可用性或真实路线；仅提供需求及活动草稿，实际地点与交通沿用现有核验。
- 用户核对汇总后生成可编辑草稿；选择或新建目标表（12 色），继续地点、路线、时间、版本及冲突核验，确认后批量保存。取消/失败/过期响应不写入。
- 持久化本地对话及生成批次。撤回只移除对应批次生成的数据，不整库回滚；后续被手动编辑或关联新路线时拒绝静默删除并说明。其他新增活动、提醒送达与已有行程保留。
- 秘钥仍按当前 Windows 用户加密；不默认发送现有数据库和私有备注，不使用或自动测试 DSH。无真实付费调用授权时用可控 HTTP 夹具验证接口。
