# 最新功能分支整合

用户明确要求直接执行：先推送当前版本备份，再以feature/ui最新分支为逻辑和交互优先级，保留本地暖色风格。备份90c1f61已上传backup/local-wpf-20261028-90c1f61。最新功能基准978c678与下载文件夹逐文件一致。

采用现有C#/WPF与SQLite，移植仓库业务流程及交互，而非把不同技术的窗口强行嵌入。原Python分支通过Git合并保留完整历史。WPF多表/周期/地图/提醒保留；删除周课表及其入口，旧WEEK偏好回退MONTH。

月历移除逐日加号，点击日期格空白打开自定义添加，卡片/复选框/日期选择按钮不误触。第一次布局和每次尺寸/视图变化按实际可视高度重新计算行最小高度；多活动行仍随内容增高。月历/列表独立缓存滚动，数据或过滤变化才失效。支持已完成/未完成过滤并本地保存。

编辑器采用仓库紧凑双列、活动标题、状态、日期/地点、起止时间/耗时、时长快捷项、备注/交通和固定底部操作；周期/提醒作为更多设置保留。允许调整窗口大小，日历/时间下拉点击外部可关闭，Escape关闭，不抢占主窗口输入。开始/结束/快捷时长联动。

自然语言采用仓库提取events结构，最多15项，先完善地点/时长/日期/截止时间/前往方式，再在08-22时按输入顺序找最早可行空档，已有活动固定；前后交通均校验。明确时间冲突拒绝，按当前Revision确认整批写入。配置支持本地规则、自定义兼容接口、百炼；DeepSeek仅提供代码与配置，不在本任务调用。已有DPAPI密钥保留，不导入Python明文配置。

新建空库自动加入明确标记的示例，临近日有0/1/2/3/5项和跨日/长备注；非空库和重启不重复注入，旧数据不迁移/覆盖。提供单独发布目录及归档。

选择：继续WPF适配，保留稳定领域存储；替换为Tk会丢现有功能，桥接两套数据库会引入一致性问题，因此不采用。实现细节与布局由执行者按用户给定优先级决定，无需再选技术栈。
