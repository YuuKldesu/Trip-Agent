# 助手地图工具与结构化行程记忆

用户已确认：助手可在对话中搜索南京地点、查询市内路线、读取相关日期生效行程，工具结果回传模型，依据实际交通重新讨论草稿。最终确认后才写数据库，保留交通卡片、手动编辑、分支和撤回。

上下文分为固定规则、北京时间、已确认需求、待确认、草稿、工具结果、当前分支历史。记忆字段采用增量更新，每条已确认事实须引用当前分支用户消息与原文片段；建议单独存放，不能当作确认。模型输出受软件验证。每条助手消息保存记忆快照，编辑旧消息从前缀快照恢复。新需求使旧路线失效。

采用现有 Chat Completions JSON 消息协议，在 JSON 中声明只读工具请求，软件执行并把带来源的结果交回；不要求服务商额外支持原生 function calling。每轮最多6次工具执行、最多5次模型工具循环，地点最多8候选、行程读取最多7天/80项，结果有大小限制；总请求120秒且可取消。高德密钥不发给模型，外部结果作为数据而非指令。

地点候选必须经对话内按钮确认（带地址），模型不能确认地点；未选地点不能生成可保存草稿。已选地点以内部引用传给完善窗口，禁止模型提供坐标。路线使用已选地点、明确出行方式与出发时间，显示费用未知、粗估/高德来源与查询时间。已有行程仅按请求日期提供标题/时间/地点/所属表，不上传备注。核对阶段仍按现有软件排程与冲突检测计算、存储交通卡片。

本地规则模式保持原能力并明确无模型工具；无地图配置明确标本地估算，不能伪装真实查询。无需新依赖；不在开发阶段调用真实收费地图/模型。不修改月历风格或顺带修复已知圆角基线检查。
