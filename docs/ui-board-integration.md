# 行程看板 UI 整合

本次只实现用户红圈内看板：采用本仓库 `app.py`（基准提交 `1e8b8593e6c16cf3b8cbbab6babf2cf0b4e46b07`）的月历、列表与暖珊瑚卡片风格，保留原WPF端多表、周期、单次例外、冲突和编辑能力。AI对话未来使用合作方逻辑，本次不接入、不修改。

## 分支与备份

- 工作分支 `codex/ui-board-integration`，从main创建；不修改main。
- 本地已备份现有源码、两个运行版本及应用Data，共911文件，SHA256逐项校验；备份不进入仓库。
- WPF端位于 `desktop-wpf/`，以已交付1.0源码为基线，对应用户截图。未交付对话改动独立保存在工作区及备份中，不混入此分支。
- 原Python入口、数据库、设置与业务逻辑保持原样。

## 界面决定

- 默认月历：周一至周日、整月网格与相邻月份淡色日期、今天标记、月份前后切换与今天按钮。
- 月历内白色紧凑活动卡，显示时间、标题、地点、耗时、备注和所属表。行高随内容扩展，滚动查看；长时活动不再占用整条时间轴。七列保持等宽，窄窗口横向滚动时星期标题同步。
- 列表：按日期分组、时间栏与白色卡片，支持点击编辑、右键删除、完成标记。初始当前月，可加载相邻月份，最多连续6个月；无限周期不展开成无限列表。超出范围可切换月份继续查看。
- 第三个“周课表”入口保留原时间轴和拖动/边缘缩放。月历支持拖动到另一日期，保留时间和周期原始实例身份。
- 保留左侧表的显示/生效和右侧详情、检查。中央看板按可见表显示；隐藏但生效的表仍参与冲突检查。
- 完成标记属于看板显示状态，按原实例键保存在Data/board.json；不取消既有排程约束，不改变SQLite结构。

## 实现和验证

1. Core/BoardProjection负责月份边界、跨日切片、实例引用和改期命令，先失败测试后实现。
2. Data/BoardPreferences保存完成标记和视图；Desktop/ScheduleBoard、BoardStyles实现月历/列表/原周课表；MainWindow只替换中央容器。
3. UI检查覆盖实际WPF窗口：月份切换、列表、周课表、显示过滤、完成标记、编辑入口、跨日与拥挤卡片；截图仅用明确标注的示例数据。
4. 原47项领域检查全部保留；新增看板检查、Release构建、独立审阅、运行包启动验证后交付。

不合并两个不同数据库，不迁移用户当前数据；新运行目录与现有版本分开。当前仅本地分支开发，若未明确要求，不推送实现代码或创建PR。
